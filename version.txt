定位
  PDF → Markdown 二模式枢纽。智能路由：自动判断调用来源并选模式；
    A 格式化存档/含公式精读（精准 API，强制）  B 临时阅读·纯文字（轻量/本地，节约 token）
  含公式禁用轻量 API（实测：希腊字母 Λ→A 错认，字符间距错误，约 108 处/30页）。

脚本清单 (scripts/)
  pdf_utils.py      probe 页数/类型(0 token) + split 分批
  mineru_precise.py 精准 API（zip：md+图，需 Key，单文件≤200页）              —— A
  merge_md.py       多批 md 拼接 + images 合并 + 衔接校验                      —— A
  img_localize.py   图片相对化 + 丢未引用图 + 图号语义重命名                  —— A
  split_md.py       超大 MD 按 BATCH BOUNDARY 拆分（Typora 2MB 适配）          —— A
  local_read.py     本地字符级分栏判断与合并（亚秒，0 token）                 —— B 文字型
  mineru_light.py   轻量 API（免 Key，仅回 md，勿用于公式）                   —— B 图片型
  concat_parts.py   归位：分批合并/单篇移动到目标目录，part 留过程            —— B 图片型

输出布局 (v1.1)
  A ≤1.5MB → 单文件 <文献名>.md；>1.5MB → <文献名>_Part01.md … (共享 img 目录)
  B → 单文件（图片型分批合并后）落目标目录；_mineru_out/ 只留过程文件。

前置条件
  Python 3.8+，pypdf、pdfminer.six、requests
  A 类需项目根 {Key}MinerU_API.txt（gitignore，90 天有效，申请：mineru.net/apiManage/token）

分批阈值
  A 精准：>200 页按 193 页/批（留 7 页裕度，精准 API 上限 200）
  B 轻量：按 20 页/批（轻量 API 上限）

language（OCR 才生效）
  中文 ch / 英文 en / 德法等 latin / 俄乌等 east_slavic
