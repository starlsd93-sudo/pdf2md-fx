
## 1、Skill简介

这是一个专门针对理工科文献和书籍的PDF智能解析工具，特别适合处理含有大量数学公式的学术文档。它能自动将PDF转换为Markdown格式，并精准提取其中的LaTeX公式，让AI可以直接学习这些公式进行推理，省去了手动敲代码的麻烦。


## 2、使用场景

我是一名研究生，每天需要阅读大量英文论文。以前遇到含有复杂公式的PDF，我只能手动把公式敲成LaTeX代码，一个积分符号都要折腾半天。有时候为了理解一个公式的推导过程，光是输入公式就要花1-2小时，更别说还要整理成结构化的文档了。

**后来有了AI，它原生支持LaTeX公式显示、编辑和理论推导。能够代替我将很多常见但是麻烦的公式转换为MATLAB程序进行验证。AI也可以调用内置的py进行数值计算。**不过怎怎么用LaTeX进行表示**依旧让我头大**。

无意中发现了一个叫MinerU的神器，它可以把我想要的文献或者书籍转换为准确的公式！但是它的转换过程操作步骤略显复杂。于是我**开发了这个Skill**

只需要把PDF扔进去，几分钟就能得到完整的Markdown文档，所有公式都自动转换成了LaTeX格式。现在我可以直接把这些文档导入AI工具，让AI帮我分析公式推导、解释理论逻辑，效率提升了至少10倍！

具体来说，这个Skill特别适合以下场景：

- **研究生阅读英文文献**：快速理解大量英文论文中的公式推导和实验数据
- **教材数字化与整理**：将纸质教材的PDF扫描件转换为可编辑的Markdown格式
- **技术文档归档**：将含有复杂公式的技术报告、规范文档转换为结构化格式
- **使用AI工具进行理论推理**：直接学习已有文献公式、无需手敲代码
- **直接借鉴书籍文献中优秀的LaTex公式**：一键复制粘贴，省时省力


## 3、使用步骤

### 如何使用这个 Skill

**第一步**：安装Skill
可以提前注册一个MinerU的API Key，使用过程中也会提示你进行注册。注册地址：https://mineru.net/apiManage/token
直接把GitHub上的.skill包上传到GPT/Claude等AI的skill里就行，有了这个skill就可以GG不用动MM全自动了。

**第二步**：准备PDF文档
把你要解析的PDF文档准备好，可以是数字版或扫描版，书籍或期刊文献都可以。

**第三步**：输入需求
告诉SOLO你想要解析哪些个PDF文档（支持批量解析，超长的书籍或者期刊文献都可以；此外扫描版也可以自动调用MinerU的ORC功能），比如"帮我解析这篇关于机器学习的论文"。

**第四步**：获取结果
等待几分钟，就能看到生成的完整Markdown文档了，所有公式都自动转换成了LaTeX格式。
